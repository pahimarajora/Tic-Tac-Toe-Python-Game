# Tic-Tac-Toe Game Using Python

## Project Overview
This project is a two-player Tic-Tac-Toe game developed using Python and Tkinter. It provides a graphical user interface where two players take turns marking X and O on a 3×3 game board.

## Features
- Interactive 3×3 game board
- Two-player gameplay
- Automatic winner detection
- Draw detection
- Scoreboard to track player scores
- Restart functionality
- User-friendly graphical interface

## Technologies Used
- Python
- Tkinter
- VS Code

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

## Game Rules
1. Player X starts first.
2. Player O takes the next turn.
3. The first player to get three matching symbols horizontally, vertically, or diagonally wins.
4. If all nine positions are filled without a winner, the game ends in a draw.
